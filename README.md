# 选出最完美的图片 · 赢礼物

微信可打开的移动端 H5 单页：点选一张图片 → 庆祝过渡页 → 礼物展示页。

直接用浏览器打开根目录的 `index.html` 即可，无需安装、无需联网。

## 使用

1. 首页点任意一张图片（当前为彩色占位块）。
2. 进入「答对了！」庆祝页，约 1.5 秒后点「查看我的礼物」。
3. 在礼物页点选「礼物A」或「礼物B」（再点一次可取消）。

## 替换真实图片

在 `index.html` 里找到 `.pic-ph` 占位框，把内部的 `<span class="pic-watermark">` 换成：

```html
<img src="你的图片地址.jpg" alt="图片1">
```

四张图分别对应 `pic-1` ～ `pic-4`。

## 修改祝福语

打开 `index.html`，改脚本顶部的配置：

```js
var CONFIG = {
  blessing: '【祝福语待填】', // 改成你的祝福语
  giftButtonDelay: 1500
};
```

详细说明见 [使用说明.md](./使用说明.md)。
